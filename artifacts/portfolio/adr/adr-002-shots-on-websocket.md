# ADR-002: выстрел и сдача только по WebSocket

**Статус:** принято (FT-055, A0089, OpenAPI).  
**Дата фиксации в витрине:** 2026-09-17.

## Контекст

Партия пошаговая, но ход Бэкенда и смена клеток должны доехать до клиента без опроса REST. Нужен один канал снимка, выстрела, сдачи и reconnect.

## Решение

Игровые мутации — кадры на `GET /sessions/{sessionId}/ws`. HTTP `POST …/shots` и `POST …/surrender` возвращают 4xx и **не** меняют сессию.

Клиент держит `PartyChannelWorker`. Sequence: [diagram-seq-001.md](../../../diagrams/diagram-seq-001.md).
