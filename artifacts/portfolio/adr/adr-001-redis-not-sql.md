# ADR-001: Redis вместо SQL

**Статус:** принято (ТЗ §2.2, факт `docker-compose.yml` и store).  
**Дата фиксации в витрине:** 2026-09-17.

## Контекст

Нужно хранить немного живых партий (лимит 3), idle TTL и глобальные счётчики. Реляционная модель полей 10×10 не даёт выгоды для MVP.

## Решение

Redis: JSON сессии с EX, SET слотов, HASH+LIST журнала. Захват слота и запись исхода — Lua.

## Следствия

Нет ER-диаграммы. Схема ключей: [diagram-redis-keys.md](../../../diagrams/diagram-redis-keys.md). Аналитика — агрегаты Session / Registry / Ledger, не таблицы.
