# ADR-003: не более трёх активных сессий

**Статус:** принято (FT-004, FT-049, A0081, `SLOT_LIMIT = 3`).  
**Дата фиксации в витрине:** 2026-09-17.

## Контекст

Локальный полигон и учебный лимит нагрузки: генерация двух валидных флотов не бесплатна; нужен понятный отказ.

## Решение

SET `seabattle:registry:slots`. Слот занимается только после успешного старта (не «бронь до расстановки»). Четвёртый `POST /sessions` → 409 `SESSION_LIMIT_REACHED`. Слот снимается сразу при `GAME_OVER` (A0128), при abort/TTL — вместе с ключом сессии.

## Следствия

Несколько окон клиента — штатный способ показать лимит. Обрыв сокета слот сам по себе не освобождает (FT-074).
