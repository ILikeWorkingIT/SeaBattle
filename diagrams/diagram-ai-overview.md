# Hunt / Target — обзор для слайда

**Тип:** flowchart  
**Срез:** упрощение UC-003 / US-003 без ID ФТ на схеме.  
**Статус:** черновик витрины. Канон ветвлений не заменяется: [diagram-mermaid-001.md](diagram-mermaid-001.md).

## Источники

Тот же ход Бэкенда, что канон: heatmap, Hunt если нет раненого, Target если есть; пустые веса — abort или победа; MISS отдаёт ход Игроку.

**Намеренно вне слайда:** крест vs ось Target, ничья весов, лимит 20 выстрелов в коде.

---

```mermaid
flowchart TD
  Start([Старт: ход Бэкенда]) --> B1{Есть раненый корабль Игрока?}
  B1 -->|нет Hunt| Hunt[Пересчёт весов по оставшимся кораблям]
  B1 -->|да Target| Target[Сузить область добивания]
  Hunt --> Pick[Клетка с max весом]
  Target --> Pick
  Pick --> B2{Есть клетка с весом больше 0?}
  B2 -->|нет| B3{Флот Игрока уничтожен?}
  B3 -->|да| EndGO([GAME_OVER победа Бэкенда])
  B3 -->|нет| EndAbort([SESSION_ABORTED удалить сессию])
  B2 -->|да| Fire[Выстрел по полю Игрока]
  Fire --> B4{Результат?}
  B4 -->|MISS| EndPlayer([Ход Игрока])
  B4 -->|HIT или SUNK флот жив| Start
  B4 -->|SUNK флот уничтожен| EndGO
```

**Проверено (§1.3):** шаги канона сжаты; heatmap в UI нет (ограничение в ADR-005, не узел).
