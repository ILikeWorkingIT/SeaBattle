# Моделирование BPMN (bpmn.io)

Прочитай и выполни `.cursor/skills/skill-diagram-bpmn.md` целиком. Команда `/diagram-bpmn` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: путь к US/UC/ТЗ/описанию процесса; создать новую диаграмму или править существующий `bpmn-NNN.bpmn`; замечания после импорта в bpmn.io; только аналитический разбор без файла / только XML.
Если текста нет — спроси источник процесса или используй явно прикреплённый `@` файл; затем создай или обнови BPMN по скиллу.

## После выполнения

Кратко: путь к `.bpmn`, ID (`bpmn-NNN`), старт / ключевые шлюзы / финалы, итог ревью синтаксиса, что править дальше. Не дублируй весь XML в чат.
