# Моделирование BPMN (bpmn.io)

Прочитай и выполни `.cursor/skills/skill-diagram-bpmn.md` целиком. Команда `/diagram-bpmn` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: путь к US/UC/ТЗ/описанию процесса; создать новую диаграмму или править существующий `bpmn-NNN.bpmn`; замечания после импорта в bpmn.io; только аналитический разбор без файла / только XML.

Если текста нет и нет `@`-файла / пути к источнику — задай вопрос с рекомендацией и **не** создавай `.bpmn` в этом ходе.
Если источник есть — создай или обнови BPMN по скиллу. Новый процесс → новый номер файла; тот же процесс → тот же файл.

Не применяй эту команду вместо `/ft`, `/nft`, `/us`, `/uc`, если задачи про диаграмму нет.

## После выполнения

Кратко: путь к `.bpmn`, ID (`bpmn-NNN`), старт / ключевые шлюзы / финалы, строка «Проверено: …», что править дальше. Не дублируй весь XML в чат.
