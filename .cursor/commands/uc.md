# Написать или обновить Use Cases

Прочитай и выполни `.cursor/skills/skill-uc.md` целиком. Команда `/uc` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: путь к ТЗ, глоссарию, ФТ, US; какие UC создать или обновить; чьи ответы обработать; только реестр / только вопросы.

Если запрос — только аудит / «проверь UC» / контроль качества без написания — **не** пиши сценарии и **не** продолжай этот скилл: следуй `.cursor/skills/skill-quality-control-us-uc.md` (команда `/qc-us-uc`).

Если текста нет — создай или дополни Use Cases и `list-uc.md` по текущим документам проекта. Не расширяй scope «для полноты». Не запускай `/qc-us-uc` без согласия.

## После выполнения

Кратко: путь папки, диапазон ID (`UC-001`…), статусы (готово / требует уточнения), какие вопросы ждут ответа (со ссылкой на `list-uc.md`). Не дублируй полные тексты всех UC в чат.
Предложи `/qc-us-uc`, не запускай без согласия. Не предлагай повторный QC, если текущие правки — перенос уже согласованных находок QC.
