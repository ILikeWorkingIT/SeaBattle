# Написать или обновить Use Cases

Прочитай и выполни `.cursor/skills/skill-uc.md` целиком. Команда `/uc` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: путь к ТЗ, глоссарию, ФТ, US; какие UC создать или обновить; чьи ответы обработать; только реестр / только вопросы.
Если текста нет — создай или дополни Use Cases и `list-uc.md` по текущим документам проекта.

## После выполнения

Кратко: путь папки, диапазон ID (`UC-001`…), статусы (готово / требует уточнения), какие вопросы ждут ответа (со ссылкой на `list-uc.md`). Не дублируй полные тексты всех UC в чат.
