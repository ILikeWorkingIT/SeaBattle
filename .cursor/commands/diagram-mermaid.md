# Моделирование в Mermaid (flowchart / DFD / class / sequence / C4)

Прочитай и выполни `.cursor/skills/skill-diagram-mermaid.md` целиком. Команда `/diagram-mermaid` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: тип диаграммы (flowchart, DFD, classDiagram, sequenceDiagram, C4); путь к US/UC/ТЗ/API/коду; создать новую или править `diagram-mermaid-NNN.md`; замечания к веткам/участникам/уровням; только разбор без файла; исключения формата (`.mmd`, только чат).

Если типа нет — уточни с рекомендацией; **не** рисуй все типы «заодно».
Если источника нет и нет `@`-файла — спроси с рекомендацией и **не** выдумывай диаграмму в этом ходе.
Если источник и тип есть — один срез, только выбранный тип (уровни DFD или C4 одного среза — в одном файле).

Не применяй эту команду вместо `/diagram-bpmn`, если нужна BPMN 2.0 для bpmn.io. Не применяй вместо `/ft`, `/nft`, `/us`, `/uc`, если задачи про диаграмму нет.

## После выполнения

Кратко: путь к `.md`, ID (`diagram-mermaid-NNN`), тип, ключевые выводы (старт/ветки/финалы или акторы/сущности/уровни). Для C4 — flowchart-эквивалент или нативный C4*. Для sequence — подтвердить прогон §4.6 и счёт `end`. Не дублируй весь файл и полный Mermaid без явной просьбы.
