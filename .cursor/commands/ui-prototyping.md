# Интерактивный макет окна фронтенда

Прочитай и выполни `.cursor/skills/skill-ui-prototyping.md` целиком. Команда `/ui-prototyping` запускает этот скилл.

## Режим

По запросу выбери **один** (скилл §0):

- **создание** — клиента нет или просят новый макет;
- **правка** — клиент есть, меняют UI (контраст, модалки, баг);
- **только запуск** — «как открыть / не вижу окно»; код не пиши.

`$1` и дальнейший текст — уточнение к выбранному режиму: какой экран; путь к US/UC/домену/ТЗ; стек из спецификации; какая правка; только способ открыть UI.

Режим **создание:** нет ни сценариев, ни `@`-файла, ни описания экрана в чате — спроси с рекомендацией и **не** выдумывай предметную область в этом ходе. Режимы **правка** и **только запуск** из-за отсутствия US/UC не останавливай.

Не применяй эту команду вместо `/ft`, `/nft`, `/us`, `/uc`, `/ddd`, если задачи про UI-макет нет.

## После выполнения

Кратко по режиму, без дубля всего кода:

- **создание** — путь к клиенту, ключевой экран, что замокано, как открыть UI самим (окно или URL, не терминал агента в чате);
- **правка** — что изменено, напомнить перезапуск тем же способом;
- **только запуск** — как открыть самим; launcher/README не переписывать, если уже есть.

Не коммить и не пиши в память агента без явной просьбы. Не переходи к API/бэкенду без согласия.
