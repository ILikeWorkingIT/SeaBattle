# Написать или обновить OpenAPI-спецификацию

Прочитай и выполни `.cursor/skills/skill-openai.md` целиком. Команда `/openai` запускает этот скилл (контракт OpenAPI / Swagger / ReDoc, **не** сервис OpenAI).

Режим — по содержимому запроса, отдельной подкоманды нет (скилл §0): **создание**, **обновление**, **только проверка**, **только запуск**.

Заключительный этап для создания, обновления и только проверки **обязателен:** гейт §8 **до** сообщения разработчику. Любая запись в YAML заканчивается §8. Пропуск гейта = работа не завершена. Чек-лист §8 — не больше **двух раз** за запуск (второй — только после правки находок). Режим **только запуск** гейт по YAML не гоняет (только §5).

## Ввод

`$1` и дальнейший текст — уточнение: путь к ФТ/UC/словарю; версия OpenAPI; имя файла; только проверка; «только отчёт без правок»; только поднять просмотрщики; порты.

Если текста нет — режим **создание** или **обновление** (файл уже есть → обновление): выполни §7 скилла целиком.

Нет ни ФТ, ни UC, ни иного описания операций — в создании **не** выдумывай API: зафиксируй пробел и спроси с рекомендацией.

Если запрос — только «проверь спецификацию» — **не** создавай второй файл: §8 (и §5 при необходимости) по существующему YAML. Дефекты правь в том же файле, если не сказано «только отчёт без правок». Нет файла — сообщи о пробеле.

«Создай» при уже лежащем YAML — режим **обновление**: правь этот файл, не копируй спецификацию в новый путь без спроса.

Если запрос — только «открой Swagger/ReDoc» — только §5; YAML и README не переписывай.

Не применяй эту команду вместо `/ft` / `/uc` / `/data-dictionary`, если задачи про контракт API нет. Не реализуй бэкенд.

## После выполнения

Кратко по §9 скилла: путь к YAML (если писали), операции и что не стало endpoint’ом, URL docs, факт гейта §8 или режим только запуска. Не дублируй спецификацию. Не утверждай контракт без согласия заказчика. Docs открывать в обычном браузере, не в Simple Browser IDE.
