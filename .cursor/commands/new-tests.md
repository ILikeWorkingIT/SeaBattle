# Создать или обновить автотесты

Прочитай и выполни `.cursor/skills/skill-new-tests.md` целиком. Команда `/new-tests` запускает этот скилл.

Не выполняй `.cursor/skills/skill-use-tests.md` в этом запуске — даже если в запросе есть «и прогони». Прогон — отдельная команда `/use-tests`.

## Ввод

`$1` и дальнейший текст — уточнение: какие экраны / API / ID требований покрыть; только инвентаризация; обновить устаревшие тесты.

Если текста нет — изучи требования и существующие тесты, добавь тесты на пробелы MVP. Не расширяй scope «для полноты». Набор не гоняй.

## Какой режим

- **дополнение** — «напиши тесты», `/new-tests`. Добавляй только непокрытое.
- **инвентаризация** — «какие тесты есть», без просьбы писать код. Файлы не создавай.
- **обновление устаревших** — канон сменился. Правь только ложные ожидания.

Продуктовый код не меняй. Папку `test-data/` не используй без прямого задания разработчика.

Если запрос — только прогон / «исправь падения» — **остановись**. Нужна `/use-tests`.

## После выполнения

Кратко: пути файлов, сколько тестов, какие ID закрыты, какие пробелы оставлены.
Предложи `/use-tests` отдельной командой.
