# Написать или обновить нефункциональные требования

Прочитай и выполни `.cursor/skills/skill-nft.md` целиком. Команда `/nft` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: путь к ТЗ, глоссарию, ФТ, что обновить, чьи ответы обработать, состав характеристик ISO 25010.

Если запрос — только аудит / «проверь НФТ» / контроль качества без написания — **не** пиши НФТ и **не** продолжай этот скилл: следуй `.cursor/skills/skill-quality-control-ft-nft.md` (команда `/qc-ft-nft`).

Если текста нет — создай или дополни НФТ по текущим документам проекта. Не расширяй scope «для полноты». Не запускай `/qc-ft-nft` без согласия.

## После выполнения

Кратко: путь файла, статус (черновик / согласовано), диапазон ID, какие вопросы ждут ответа.
Предложи `/qc-ft-nft`, не запускай без согласия. Не предлагай повторный QC, если текущие правки — перенос уже согласованных находок QC.
