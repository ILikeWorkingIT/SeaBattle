# Написать или обновить User Stories

Прочитай и выполни `.cursor/skills/skill-us.md` целиком. Команда `/us` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: путь к ТЗ, глоссарию, ФТ; какие US обновить; чьи ответы обработать; только роли / только реестр.

Если запрос — только аудит / «проверь US» / контроль качества без написания — **не** пиши истории и **не** продолжай этот скилл: следуй `.cursor/skills/skill-quality-control-us-uc.md` (команда `/qc-us-uc`).

Если текста нет — создай или дополни User Stories, роли и реестр по текущим документам проекта. Не расширяй scope «для полноты». Не запускай `/qc-us-uc` без согласия.

## После выполнения

Кратко: путь папки, диапазон ID (`US-001`…), статусы (готово / требует уточнения), какие вопросы ждут ответа. Не дублируй все AC в чат.
Предложи `/qc-us-uc`, не запускай без согласия. Не предлагай повторный QC, если текущие правки — перенос уже согласованных находок QC.
