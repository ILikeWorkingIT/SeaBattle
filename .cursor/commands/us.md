# Написать или обновить User Stories

Прочитай и выполни `.cursor/skills/skill-us.md` целиком. Команда `/us` запускает этот скилл.

## Ввод

`$1` и дальнейший текст — уточнение: путь к ТЗ, глоссарию, ФТ; какие US обновить; чьи ответы обработать; только роли / только реестр.
Если текста нет — создай или дополни User Stories, роли и реестр по текущим документам проекта.

## После выполнения

Кратко: путь папки, диапазон ID (`US-001`…), статусы (готово / требует уточнения), какие вопросы ждут ответа. Не дублируй все AC в чат.
