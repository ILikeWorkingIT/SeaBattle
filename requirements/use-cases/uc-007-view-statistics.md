# UC-007: Просмотреть глобальную статистику сервера

**Статус артефакта:** `Согласовано`, 2026-08-25 (A0146)  
**Уровень:** user goal  
**Связанные US:** US-007  
**Связанные ФТ:** FT-038, FT-039, FT-040, FT-041, FT-042, FT-056  
**Источники:** ТЗ §2.1–2.2; A0015; A0027; A0088; A0103; A0114; A0146; A0121; A0134; A0135

---

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Игрок | Primary | Запрашивает просмотр статистики |
| Фронтенд | Supporting | Вызывает API статистики (REST), отображает счётчики |
| Бэкенд | Supporting | Отдаёт глобальные агрегаты по записям завершённых партий |

---

## 2. Предусловие

- Фронтенд может обратиться к Бэкенду.
- Логин не требуется (статистика глобальная, не персональная).
- Запрос допустим в том числе во время активной партии Игрока (A0121).

---

## 3. Триггер

Игрок через Фронтенд запрашивает глобальную статистику сервера (в т.ч. с экрана партии).

---

## 4. Основной поток

1. Фронтенд запрашивает у Бэкенда актуальные данные (обязательного кэша нет; краткий кэш сеанса допустим, после собственного `GAME_OVER` — обновить с Бэкенда, A0135). Точный JSON-контракт — при разработке API (A0134).
2. Бэкенд читает записи завершённых партий (`GAME_OVER`) и агрегаты.
3. Бэкенд возвращает: число сыгранных игр; число побед Игрока; число побед Бэкенда; среднее число выстрелов (ход = один выстрел; среднее по записям; при нуле записей — 0).
4. Запрос **не** сдвигает idle TTL активной сессии Игрока (если она есть) и **не** меняет состояние партии.
5. Фронтенд отображает полученные счётчики Игроку.
6. Сценарий завершается без влияния на текущий бой.

---

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 1.1]** Запрос с неверным методом / путём / типом, не соответствующим контракту статистики.

1. Бэкенд отклоняет без изменения статистики и партий.
2. **Завершение** с ошибкой запроса на Фронтенде.

### 5.2. Timeout / недоступность

**[Шаг 1.2]** Бэкенд недоступен или ответ не получен.

1. Фронтенд сообщает о невозможности загрузить статистику.
2. Состояние партии (если есть) не меняется; TTL не сдвигается этим неуспешным запросом.
3. **Завершение** попытки; возможен повтор с шага 1.

### 5.3. Прерывание

**[Шаг 1.3]** Игрок уходит с экрана статистики до ответа.

1. UI прекращает ожидание отображения.
2. Ответ Бэкенда, если пришёл, может быть отброшен UI.
3. **Завершение** UI-сценария; данные на сервере не менялись.

### 5.4. Недостаточно прав

**Не применимо как RBAC.** В MVP любой Игрок через Фронтенд может читать глобальную статистику; персональной статистики и логина нет (A0015, A0016). Запись статистики Фронтендом запрещена (см. UC-004) — это не часть данного UC чтения.

### 5.5. Конкурентный доступ

**[Шаг 2.1]** Во время запроса на другой сессии фиксируется новый `GAME_OVER` (UC-004).

1. Ответ отражает согласованный снимок на момент чтения (до или после новой записи — одна из допустимых точек чтения).
2. Партии Игрока не мутируются запросом статистики.
3. **Возврат** к шагу 3–5 с полученным снимком.

### 5.6. Граничные значения

**[Шаг 3.1]** Ноль завершённых партий — все счётчики игр/побед = 0; среднее = 0.

**[Шаг 3.2]** Оборванные партии и удаления по TTL / `SESSION_ABORTED` в счётчики не входят.

**[Шаг 4.1]** Запрос статистики при активной партии и при отсутствии партии — одинаково допустим; TTL активной сессии не сдвигается.

---

## 6. Потоки исключений

### E1. Повреждённые / несогласованные записи статистики на Бэкенде

1. Бэкенд не должен отдавать заведомо противоречивый набор (например, побед больше, чем игр) без обработки; при сбое — ошибка чтения.
2. Фронтенд показывает ошибку загрузки.
3. **Завершение** без отображения частичных «тихих» цифр, если контракт запрещает; иначе — явная ошибка.

### E2. Попытка изменить статистику через этот же API

1. Метод чтения не изменяет агрегаты; попытка write отклоняется.
2. **Завершение** отказа; данные меняет только UC-004.

---

## 7. Постусловие

**Успех:** Игрок видит актуальные глобальные счётчики; партия и TTL не изменены запросом; статистика по-прежнему только из прошлых `GAME_OVER`.

**Отказ:** счётчики не показаны или показано сообщение об ошибке; серверное состояние партий не изменено.
