## Проверка качества пакета UC (2026-08-25)

Чек-лист: `skill-uc` §10. Критерии заказчика: акторы, предусловие, триггер, основной поток 5–8 шагов, 6 категорий альтернатив, исключения, постусловие, вопросы; статусы реестра `готово` / `требует уточнения`; источник; согласованность с ФТ и глоссарием.

| # | Критерий | Итог |
| --- | --- | --- |
| 1–2 | Один primary из источников; нет суррогата «Пользователь» | OK; UC-006: primary = Фронтенд, Игрок = interested (уточнено 2026-08-25) |
| 3 | Акторы, предусловие, триггер, поток 5–8, постусловие | OK: UC-001…006,008 — по 7 шагов; UC-007 — 6 |
| 4 | Шесть категорий альтернатив + возврат/завершение / N/A | OK у всех восьми |
| 5 | ≥2 исключения | OK (E1, E2) у всех |
| 6 | Источники (§1.1) | OK |
| 7 | Термины / глоссарий | OK (Бэкенд, Фронтенд, коды исходов) |
| 8 | include/extension | OK (UC-004 как extension; связи в реестре) |
| 9–10 | Лимиты; вне scope | OK; вне MVP — через US/ФТ, отдельных UC нет |
| 11–12 | Вопросы только в реестре; статусы | OK: открытых нет; все `готово` |
| 13–14 | Именование; закрытые ответы | OK: A0115–A0137 отражены |
