# UC-008: Сменить язык интерфейса

**Статус артефакта:** `Черновик, требует согласования`  
**Уровень:** user goal  
**Связанные US:** US-008  
**Связанные ФТ:** FT-008, FT-059, FT-060, FT-061, FT-062, FT-073  
**Источники:** ТЗ §5; A0029; A0049; A0091; A0114; A0136; A0137; NFT-016

---

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Игрок | Primary | Выбирает язык в меню |
| Фронтенд | Supporting / исполнитель | Меняет подписи и координаты; хранит выбор локально |
| Бэкенд | — | Не участвует в хранении языка сессии (A0091) |

---

## 2. Предусловие

- Фронтенд запущен.
- Доступны языки интерфейса: русский и английский.
- При первом запуске язык уже определён по FT-060 (ОС RU/EN → соответствующий; иначе EN), если Игрок ещё не выбирал язык ранее.

---

## 3. Триггер

Игрок выбирает в меню Фронтенда русский или английский язык интерфейса.

---

## 4. Основной поток

1. Игрок открывает пункт меню смены языка (FT-061).
2. Игрок выбирает русский или английский.
3. Фронтенд сразу обновляет все команды и подписи экрана на выбранном языке.
4. Фронтенд обновляет отображение координат поля: RU — А–К без «Ё» и «Й», 1–10; EN — A–J, 1–10 (FT-008).
5. Фронтенд сохраняет выбор в локальных настройках на машине игрока для следующих запусков (FT-062, A0091, A0136). При смене версии приложения: если ключ языка есть — использовать его; иначе — FT-060. Полный перечень ключей локализации — при разработке UI (A0137).
6. Если есть активная партия: сессия **не** пересоздаётся; коды клеток в состоянии **не** меняются; idle TTL **не** сдвигается (FT-073).
7. Игрок продолжает текущий сценарий (меню, партия, статистика) на новом языке.

---

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 2.1]** В меню передано значение языка вне {RU, EN} (сбой UI / ручная подмена настройки).

1. Фронтенд игнорирует недопустимое значение или откатывается к последнему валидному / EN.
2. Сессия на Бэкенде не затрагивается.
3. **Возврат** к прежнему языку отображения или **завершение** с сохранением прежнего валидного языка.

### 5.2. Timeout / недоступность

**Не применимо к Бэкенду.** Смена языка выполняется локально на Фронтенде (A0091). Недоступность Бэкенда не блокирует смену подписей UI.

**[Шаг 5.1]** Ошибка записи локального хранилища языка.

1. Текущий сеанс всё равно может показать новый язык (шаги 3–4).
2. При следующем запуске язык может вернуться к FT-060 / прошлому сохранённому.
3. **Завершение** текущего UI-успеха с риском несохранения; либо сообщение о сбое сохранения — на усмотрение реализации.

### 5.3. Прерывание

**[Шаг 2.2]** Игрок закрывает меню без выбора.

1. Язык не меняется.
2. **Завершение** без побочных эффектов.

### 5.4. Недостаточно прав

**Не применимо.** В MVP нет ролей, ограничивающих смену языка; действие локальное. Бэкенд язык не «разрешает» и не хранит.

### 5.5. Конкурентный доступ

**[Шаг 2.3]** Быстрые повторные переключения RU↔EN.

1. Фронтенд применяет последний выбранный валидный язык; подписи согласованы с ним (NFT-016: после смены нет «старых» подписей).
2. Идентификатор и состояние сессии неизменны.
3. **Возврат** к шагу 3–6 для финального выбора.

### 5.6. Граничные значения

**[Шаг 6.1]** Смена языка при активной партии — только UI и координаты на экране; двухцифровые коды в состоянии прежние.

**[Шаг 6.2]** Смена языка без активной партии — то же для меню/экранов; сессия не создаётся.

**[Шаг 0.1 — первичный запуск]** (связанный поток, не меню): язык ОС не RU/EN → интерфейс EN (FT-060); далее Игрок может сменить через этот UC.

---

## 6. Потоки исключений

### E1. Часть строк UI осталась на прежнем языке после смены

1. Нарушение NFT-016 / FT-061.
2. Фронтенд должен завершить полную смену ресурсов языка.
3. **Возврат** к шагу 3 до полной согласованности или повторный выбор языка.

### E2. Ошибочное пересоздание сессии или смена кодов клеток из-за смены языка

1. Запрещено FT-073.
2. При обнаружении — дефект; корректное поведение: только подписи/координаты на экране.
3. **Завершение** с сохранением той же сессии и тех же кодов в состоянии.

---

## 7. Постусловие

**Успех:** UI и координаты на выбранном языке; выбор сохранён локально (если запись удалась); активная сессия та же; TTL не сдвинут; Бэкенд язык не хранит.

**Отмена / невалидный выбор:** язык прежний; сессия не затронута.
