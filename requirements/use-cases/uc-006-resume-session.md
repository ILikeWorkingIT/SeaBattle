# UC-006: Возобновить партию (автовозобновление соединения)

**Статус артефакта:** `Черновик, требует согласования`  
**Уровень:** user goal  
**Связанные US:** US-006  
**Связанные ФТ:** FT-002, FT-005, FT-053, FT-054, FT-066, FT-067, FT-068, FT-074, FT-080  
**Источники:** A0001; A0002; A0023; A0093; A0094; A0097; A0104; A0107; A0114; A0120; A0132; A0133; NFT-007

---

## 1. Акторы

| Роль | Тип | Участие |
| --- | --- | --- |
| Игрок | Primary (косвенно) | Продолжает партию в том же запуске Фронтенда |
| Фронтенд | Supporting / инициатор | Автоматически восстанавливает канал; показывает TTL |
| Бэкенд | Supporting | Отдаёт состояние по id, пока TTL не истёк; отклоняет второй клиент |

---

## 2. Предусловие

- Ранее была создана игровая сессия, идентификатор известен **этому** запуску Фронтенда.
- Idle TTL 30 минут ещё не истёк (иначе отказ).
- Отдельного экрана ввода id в MVP нет (A0093).

---

## 3. Триггер

Соединение с каналом партии оборвалось, и Фронтенд того же запуска пытается восстановить канал к сессии.

---

## 4. Основной поток

1. Фронтенд инициирует повторное подключение к сессии по идентификатору, хранящемуся только в памяти текущего запуска (A0132; без UI ввода id).
2. Бэкенд проверяет: сессия существует; TTL не истёк; нет другого активного соединения иного Фронтенда. Повторное подключение того же запуска замещает прежнее соединение и считается возобновлением, не вторым клиентом (A0133, FT-068).
3. Бэкенд возвращает актуальное оперативное состояние: матрицы полей, история выстрелов, текущий ход (FT-002, FT-054).
4. Возобновление **не** сдвигает idle TTL само по себе (сдвигают только создание и выстрел).
5. Фронтенд восстанавливает отображение партии, включая оставшееся время idle TTL в любом читаемом формате (FT-080, A0120).
6. Игрок продолжает с текущего права хода (UC-002 или ожидание UC-003).
7. Сценарий считается возобновлением, а не вторым Фронтендом (FT-068, A0133).

---

## 5. Альтернативные потоки

### 5.1. Некорректные данные

**[Шаг 1.1]** Фронтенд передаёт пустой / заведомо битый идентификатор.

1. Бэкенд отвечает единым отказом «сессия недоступна» (FT-067, A0097) без различия причин для клиента.
2. **Завершение.** Новая партия — UC-001.

### 5.2. Timeout / недоступность

**[Шаг 1.2]** Бэкенд недоступен при попытке возобновления.

1. Фронтенд сообщает о недоступности сервера и может повторять попытки, пока жив процесс и не истёк локальный смысл сессии.
2. **Возврат** к шагу 1 при следующей попытке или **завершение** ожидания по политике UI.

**[Шаг 2.1]** Idle TTL истёк; состояние удалено (FT-053).

1. Отказ «сессия недоступна»; при наличии связи — оповещение об истечении TTL (FT-066).
2. `GAME_OVER` и статистика не меняются.
3. **Завершение.**

### 5.3. Прерывание

**[Шаг 1.3]** Игрок полностью перезапускает приложение Фронтенда.

1. В MVP автовозобновление прошлого запуска и ввод id **не** поддерживаются (A0093, A0104).
2. Если состояние ещё на Бэкенде — слот лимита занимает его до TTL / иного завершения.
3. **Завершение** без восстановления партии на новом запуске.

### 5.4. Недостаточно прав

**[Шаг 2.2]** Попытка подключиться к сессии, к которой нет права у этого клиента (чужой id).

1. Единый отказ «сессия недоступна» без раскрытия, существует ли сессия (A0001, A0097).
2. Состояние чужой сессии не выдаётся.
3. **Завершение**.

### 5.5. Конкурентный доступ

**[Шаг 2.3]** К сессии уже есть активное соединение другого экземпляра Фронтенда (FT-068).

1. Второе подключение отклоняется; первый клиент удерживает сессию.
2. **Завершение** для второго клиента.

**[Шаг 2.4]** После обрыва тот же запуск подключается снова — это основной поток (не «второй Фронтенд»).

### 5.6. Граничные значения

**[Шаг 2.5]** Возобновление за секунды до истечения TTL — успех, если TTL ещё не истёк; TTL возобновлением не продлевается.

**[Шаг 5.1]** Показ оставшегося TTL при нулевом/минимальном остатке — Фронтенд отображает актуальное оставшееся время до удаления.

**[Шаг 2.6]** Сессия удалена после сбоя heatmap (FT-075) — отказ как у неизвестной сессии (FT-067).

---

## 6. Потоки исключений

### E1. Состояние на Бэкенде есть, снимок при возобновлении семантически неполный

1. Нарушение NFT-007 / FT-054: доля успешных возобновлений с эквивалентным состоянием должна быть 100% в приёмке.
2. Игрок не должен продолжать по повреждённому снимку: отказ либо повторная выдача полного состояния.
3. **Возврат** к шагу 3 при повторной успешной выдаче или **завершение** с отказом «сессия недоступна».

### E2. Гонка: TTL истекает между проверкой и выдачей состояния

1. Сессия удаляется; клиент получает отказ / FT-066.
2. Статистика не меняется.
3. **Завершение**.

---

## 7. Постусловие

**Успех:** один активный Фронтенд снова связан с сессией; состояние совпадает с сохранённым; TTL не сдвинут возобновлением; TTL видно Игроку; партия продолжаема.

**Отказ:** единого вида «сессия недоступна»; новая партия только через UC-001; при TTL — без `GAME_OVER`.
