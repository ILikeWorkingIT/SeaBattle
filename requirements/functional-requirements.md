# Функциональные требования

**Статус:** `Согласовано` (2026-08-24). Дополнено решениями по отчёту `reports/incompatibility-ft-nft.md` (2026-08-24).

**Контекст:** `requirements/glossary.md`  
**Источник правды:** `documentation/specification-sea-battle-v1-1.md`; закрытые решения — `requirements/answers-project.md` (Axxxx)  
**Нумерация:** с `FT-001`. Последний ID: `FT-079`. Снятые ID (не переиспользовать): FT-035, FT-037, FT-057, FT-078.

Термины и коды (`MISS`, `HIT`, `SUNK`, `GAME_OVER`, Hunt Mode, Target Mode, игровая сессия) — по глоссарию. Формулировки без стека и UI-решений.

Приоритет MoSCoW:

- **Must** — без этого нельзя провести партию PvE по правилам ТЗ;
- **Should** — заявлено в целях или контрактах ТЗ, но партия как таковая без этого возможна;
- **Could** — следует из ТЗ слабо или уточняет представление, не механику.
