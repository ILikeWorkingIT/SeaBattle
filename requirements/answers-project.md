## Назначение и формат файла базы ответов

- **Назначение:** единственное хранилище **закрытых** ответов на вопросы агента; источник данных для колонки «Источник» в требованиях (`Axxxx`).
- **Когда заполнять:** после ответов пользователя в чате или в файле артефакта (см. `.cursor/rules/rule-answers-project.mdc`). Вопросы без ответа сюда не писать.
- **Формат ID:** латинская `A` + 4 цифры (`A0001`). Номер выдаёт агент по возрастанию; пропуски допустимы.
- **Колонки:** `Номер` (= ID) | `Код` (тип артефакта: `FT`, `NFT`, `US`, `UC`, `DDD`, `API`, …) | `Вопрос` | `Ответ`. Один вопрос — один код. Автора не указывать.
- **Ответ:** дословно текст пользователя; если только «да» / «согласен» — текст рекомендации агента.
- **Даты:** секция `## Дата YYYY-MM-DD` — день внесения ответов. Новый день — новая секция. Правка решения = удалить старую строку + новый ID (дату старой секции не менять).
- **Приоритет:** ответ в этом файле уточняет предварительное ТЗ и при конфликте важнее ТЗ. В требованиях ссылаться просто `A0001`.
- **Конфликты двух Axxxx:** не править молча — ждать решения пользователя.
- **Не путать** с ID правил измерения в НФТ (`MR-01`…`MR-07`).
