# US-007: Просмотреть глобальную статистику сервера

## User Story

```text
As a Игрок,
I want запросить глобальную статистику сервера,
So that я вижу общие результаты завершённых партий без привязки к логину.
```

**Статус:** `Черновик, требует согласования`  
**Приоритет (MoSCoW):** Should  
**Источник:** [ТЗ](../../documentation/specification-sea-battle-v1-1.md) §2.1–2.2; A0015; A0027; A0088; A0103  
**Связанные ФТ:** FT-038, FT-039, FT-040, FT-041, FT-042, FT-056

## Acceptance Criteria (Gherkin)

### AC1 — Выдача статистики по запросу

```gherkin
Given десктопный клиент может обратиться к серверу
When Игрок запрашивает статистику
Then система предоставляет глобальную статистику сервера
And в MVP статистика не разделяется по игрокам
```

### AC2 — Состав счётчиков

```gherkin
Given Игрок запросил статистику
When система возвращает ответ
Then в статистике доступны: число сыгранных игр, число побед Игрока, число побед серверного ИИ, среднее число выстрелов
And «ход» для среднего означает один выстрел
And среднее считается по записям завершённых игр (A0088, A0103)
```

### AC3 — Запрос статистики не двигает TTL и не завершает партию

```gherkin
Given у Игрока есть активная игровая сессия
When он запрашивает статистику
Then idle TTL сессии не сдвигается из-за этого запроса
And состояние партии не меняется
And статистика отражает только ранее зафиксированные GAME_OVER
```

### AC4 — Edge case: ноль завершённых партий и оборванные партии

```gherkin
Given на сервере ещё не было ни одной партии с GAME_OVER
When Игрок запрашивает статистику
Then среднее число выстрелов равно 0

Given партия оборвана или удалена по idle TTL без GAME_OVER
When Игрок запрашивает статистику
Then такая партия не входит в счётчики глобальной статистики
```
