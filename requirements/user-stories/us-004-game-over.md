# US-004: Завершить партию победой или поражением

## User Story

```text
As a Игрок,
I want чтобы партия завершалась при уничтожении флота одного из участников и фиксировался победитель,
So that исход матча однозначен и учитывается в глобальной статистике сервера.
```

**Статус:** `Черновик, требует согласования`  
**Приоритет (MoSCoW):** Must  
**Источник:** [ТЗ](../../documentation/specification-sea-battle-v1-1.md) §2.2, §3.3; A0005; A0027; A0088; A0103  
**Связанные ФТ:** FT-025, FT-026, FT-038, FT-039, FT-040, FT-041, FT-047, FT-056, FT-071

## Acceptance Criteria (Gherkin)

### AC1 — Победа Игрока

```gherkin
Given у серверного ИИ осталась последняя непоражённая палуба флота
When Игрок уничтожает эту палубу
Then система фиксирует SUNK и отдельно GAME_OVER в том же исходе
And фиксируется победа Игрока
And клиент получает оповещение о GAME_OVER
And глобальная статистика обновляется только из-за этого GAME_OVER
```

### AC2 — Победа серверного ИИ

```gherkin
Given у Игрока осталась последняя непоражённая палуба флота
When серверный ИИ уничтожает эту палубу
  Or при пустой heatmap выполняется проверка победы ИИ и флот Игрока уничтожен
Then система фиксирует GAME_OVER
And фиксируется победа серверного ИИ
And глобальная статистика обновляется согласно правилам начисления при GAME_OVER
```

### AC3 — Счётчики статистики при конце партии

```gherkin
Given наступило GAME_OVER
When система обновляет глобальную статистику
Then сохраняется запись завершённой партии (A0088, A0103)
And увеличивается число сыгранных игр
And увеличивается счётчик побед победившей стороны
And пересчитывается среднее число выстрелов по записям завершённых партий
And при нуле завершённых партий до этого события среднее равно 0
```

### AC4 — Edge case: действия после GAME_OVER

```gherkin
Given партия уже завершена с GAME_OVER
When Игрок пытается выполнить выстрел
Then система отклоняет выстрел
And состояние завершённой партии и статистика из-за этого запроса не меняются
```
