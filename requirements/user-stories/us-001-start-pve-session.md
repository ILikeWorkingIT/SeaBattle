# US-001: Начать партию против Бэкенда

## User Story

```text
As a Игрок,
I want начать новую партию в режиме PvE против Бэкенда и получить свою расстановку флота,
So that я могу сразу играть по правилам «Морского боя» без ручной расстановки.
```

**Статус:** `Черновик, требует согласования`  
**Приоритет (MoSCoW):** Must  
**Источник:** [ТЗ](../../documentation/specification-sea-battle-v1-1.md) §1, §2.1, §3.1–3.2; A0012; A0081  
**Связанные ФТ:** FT-001, FT-004, FT-006, FT-009, FT-010, FT-011, FT-012, FT-013, FT-014, FT-015, FT-016, FT-043, FT-049, FT-050, FT-069

## Acceptance Criteria (Gherkin)

### AC1 — Успешный старт партии

```gherkin
Given активных игровых сессий меньше трёх
When Игрок запрашивает начало новой партии
Then система создаёт игровую сессию в режиме PvE
And выдаёт Игроку валидную расстановку его флота (10 кораблей / 20 палуб)
And скрывает расстановку Бэкенда и матрицу вероятностей
And передаёт право первого хода Игроку
And учитывает сессию в лимите активных сессий
```

### AC2 — Состав и правила расстановки

```gherkin
Given Игрок успешно начал партию
When он просматривает своё поле
Then флот содержит 1 линкор, 2 крейсера, 3 эсминца и 4 катера
And каждый корабль размещён строго горизонтально или вертикально
And между любыми точками разных кораблей есть минимум одна пустая клетка (включая углы)
```

### AC3 — Отказ при лимите сессий

```gherkin
Given уже есть три активные игровые сессии
When Игрок запрашивает начало новой партии
Then система отказывает в создании сессии
And не занимает четвёртый слот
And не меняет глобальную статистику
```

### AC4 — Edge case: не удалось получить валидную расстановку в окне старта

```gherkin
Given Игрок запросил начало партии
And за окно создания сессии валидная расстановка не получена
When система завершает попытку старта
Then Игрок получает единое сообщение об ошибке старта
And сессия не создаётся
And слот лимита активных сессий не занимается
And глобальная статистика не меняется
And выстрел до успешного старта отклоняется
```
