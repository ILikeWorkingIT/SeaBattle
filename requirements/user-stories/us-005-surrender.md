# US-005: Сдаться / выйти из незавершённой партии

## User Story

As a Игрок,
I want явно выйти из незавершённой партии (сдача),
So that матч сразу завершается победой Бэкенда и я могу прекратить бой.

**Статус:** `Согласовано`, 2026-08-25 (A0114)  
**Приоритет (MoSCoW):** Must  
**Источник:** A0114; A0092; A0100; FT-077  
**Связанные ФТ:** FT-077, FT-025, FT-026, FT-056, FT-040

## Acceptance Criteria (Gherkin)

### AC1 — Явный выход = сдача

Given партия не завершена
When Игрок явно запрашивает выход из партии
Then система фиксирует GAME_OVER
And победителем становится Бэкенд
And Фронтенд получает оповещение о GAME_OVER

### AC2 — Статистика при сдаче

Given Игрок сдался (явный выход из незавершённой партии)
When система обрабатывает GAME_OVER
Then глобальная статистика обновляется как при обычном завершении партии
And увеличивается число игр и число побед Бэкенда
And учитываются выстрелы этой партии в среднем числе выстрелов

### AC3 — На своём ходе: выстрел или выход

Given у Игрока есть право хода
And партия не завершена
When он продолжает партию
Then доступны выстрел по полю Бэкенда либо явный выход (= сдача)

### AC4 — Edge case: выход на ходе Бэкенда и после конца; обрыв ≠ сдача

Given право хода у Бэкенда
And партия не завершена
When Игрок явно запрашивает выход из партии
Then система фиксирует GAME_OVER с победой Бэкенда (A0092)

Given партия уже завершена GAME_OVER
When Игрок закрывает Фронтенд или нажимает выход
Then повторная сдача и повторный GAME_OVER не фиксируются

Given партия не завершена
When соединение обрывается без явного выхода
Then это не считается сдачей
And сессия остаётся активной до истечения idle TTL (FT-074)
