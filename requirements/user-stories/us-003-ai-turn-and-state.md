# US-003: Получать ход Бэкенда и смену состояния партии

## User Story

As a Игрок,
I want получать выстрелы Бэкенда и оповещения о смене состояния партии,
So that я вижу актуальный ход боя и могу реагировать, когда право хода снова у меня.

**Статус:** `Согласовано`, 2026-08-25 (A0114)  
**Приоритет (MoSCoW):** Must  
**Источник:** A0114; [ТЗ](../../documentation/specification-sea-battle-v1-1.md) §2.1, §4; A0009; A0095; A0106  
**Связанные ФТ:** FT-027, FT-028, FT-029, FT-030, FT-031, FT-032, FT-033, FT-034, FT-036, FT-050, FT-052, FT-058, FT-064, FT-065, FT-075, FT-076, FT-079

## Acceptance Criteria (Gherkin)

### AC1 — Выстрел Бэкенда при его праве хода

Given право хода у Бэкенда
And партия не завершена
When Бэкенд выполняет ход
Then он пересчитывает матрицу вероятностей 10?10 перед выстрелом
And выбирает клетку с наибольшим весом (при равенстве — случайно из лидеров)
And выполняет выстрел по полю Игрока
And Фронтенд получает оповещение о событии выстрела Бэкенда, результате (MISS / HIT / SUNK) и смене права хода при необходимости
And матрица вероятностей Игроку не показывается
And режимы Hunt Mode / Target Mode игроку не подсказываются в UI (A0095)

### AC2 — Hunt Mode и Target Mode

Given нет раненого непотопленного корабля Игрока
When Бэкенд готовит выстрел
Then активен Hunt Mode
And веса свободных клеток считаются по числу способов разместить оставшиеся корабли с учётом их количества, промахов и потопленных зон

Given есть раненый, но ещё не потопленный корабль Игрока
When Бэкенд готовит выстрел
Then активен Target Mode
And при одном HIT релевантен непроверенный ортогональный крест
And при двух и более HIT на линии релевантны только продолжения этой оси до края поля или до MISS
And вероятности клеток вне области Target Mode обнуляются
And при нескольких раненых кораблях Бэкенд добивает один до SUNK прежде чем переходить к другому

### AC3 — Перечень оповещений о смене состояния

Given активная игровая сессия с подключённым Фронтендом
When происходит смена права хода, результат выстрела любой стороны, GAME_OVER или выстрел Бэкенда
Then Фронтенд получает соответствующее оповещение в составе согласованного перечня
And отдельного push о создании сессии сверх ответа на старт нет

### AC4 — Edge case: пустая heatmap

Given право хода у Бэкенда
And нет свободных клеток с ненулевым весом
When система обрабатывает ход Бэкенда
Then выстрел не выполняется
And сначала проверяется условие победы Бэкенда
And если флот Игрока уничтожен, фиксируются GAME_OVER и статистика
And если флот Игрока ещё не уничтожен, Фронтенд сначала получает сообщение о сбое партии с событием SESSION_ABORTED и текстом RU/EN о прерывании и необходимости начать новую партию (A0106)
And затем состояние сессии удаляется, слот лимита освобождается, статистика не меняется
And последующее возобновление даёт единый отказ «сессия недоступна» (A0001, A0097)
