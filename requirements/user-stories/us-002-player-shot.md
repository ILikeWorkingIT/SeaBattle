# US-002: Выполнить выстрел по полю Бэкенда

## User Story

```text
As a Игрок,
I want на своём ходе выстрелить по клетке поля Бэкенда и увидеть результат,
So that я могу повреждать и топить флот Бэкенда по правилам партии.
```

**Статус:** `Черновик, требует согласования`  
**Приоритет (MoSCoW):** Must  
**Источник:** [ТЗ](../../documentation/specification-sea-battle-v1-1.md) §3.1, §3.3; A0011; A0089; A0099; A0102  
**Связанные ФТ:** FT-007, FT-008, FT-017, FT-018, FT-019, FT-020, FT-021, FT-022, FT-023, FT-024, FT-044, FT-045, FT-046, FT-047, FT-048, FT-051, FT-055, FT-063, FT-070, FT-071, FT-072

## Acceptance Criteria (Gherkin)

### AC1 — Промах передаёт ход

```gherkin
Given у Игрока есть право хода
And партия не завершена
When Игрок выполняет выстрел по клетке поля Бэкенда без палубы
Then система фиксирует результат MISS
And право хода переходит Бэкенду
And Фронтенд получает оповещение о результате и смене права хода
And на поле Бэкенда клетка промаха отображается как «тире» (A0099)
```

### AC2 — Попадание и потопление сохраняют ход

```gherkin
Given у Игрока есть право хода
When Игрок выполняет выстрел по палубе корабля Бэкенда, который ещё не уничтожен целиком
Then система фиксирует HIT
And право хода остаётся у Игрока
And на поле Бэкенда клетка отображается как «звёздочка» (ранен, A0099)

Given у Игрока есть право хода
When Игрок уничтожает последнюю палубу корабля Бэкенда
Then система фиксирует SUNK
And клетка последней палубы имеет статус SUNK
And клетки периметра потопленного корабля хранятся и отдаются Фронтенду как MISS
And право хода остаётся у Игрока
And клетки потопленного корабля на поле Бэкенда отображаются как «X» (убит, A0099)
And клетки буферной зоны отображаются как «тире», без отдельного значка буфера (A0099)
```

### AC3 — Координаты, канал и вид непроверенных клеток

```gherkin
Given у Игрока есть право хода
When он выбирает клетку для выстрела
Then на экране координаты показаны буквами текущего языка интерфейса и числами 1–10
And выстрел принимается только по каналу партии реального времени
And в состоянии клетки кодируются двухцифровым кодом столбец-строка
And непроверенные клетки поля Бэкенда отображаются одинаково пустыми (A0099)
```

### AC4 — Edge case: нелегальный или гоночный выстрел

```gherkin
Given партия активна
When Игрок пытается выстрелить в уже проверенную клетку
  Or выстрелить вне поля / вне индексов [0..9, 0..9]
  Or выстрелить без права хода
  Or выстрелить после GAME_OVER
  Or выстрелить по полю своего флота
  Or передать выстрел не по каналу партии реального времени
  Or отправить выстрел без координат / с неверным типом полезной нагрузки
Then система отклоняет запрос без изменения состояния партии
And при выстреле не по каналу партии Фронтенд получает код SHOT_WRONG_CHANNEL и короткий текст (A0089)

Given у Игрока есть право хода
And система уже приняла первый выстрел этого хода
When поступают одновременные дополнительные запросы выстрела той же стороны
Then система отклоняет все запросы после первого
```
