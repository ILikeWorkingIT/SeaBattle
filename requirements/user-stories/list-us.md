# Реестр ролей и прав пользователей (list-us)

**Проект:** Sea Battle  
**Дата:** 2026-08-25  
**Статус:** `Черновик, требует согласования`  
**Связанные US:** `us-registry.md`  
**Источники:** глоссарий, ФТ, `answers-project.md` (в т.ч. A0016, A0048, A0089–A0097)

В MVP **нет логина и идентификатора игрока**. Доступ к конкретной партии — по **идентификатору игровой сессии** (секрет доступа). Права ниже — логические возможности сторон, не RBAC-роли СУБД.

Термин **Бэкенд** в глоссарии — серверная сторона партии (в т.ч. ход Heatmap Bot). Синонимы в глоссарии: серверный ИИ, бот, Heatmap Bot.

---

## 1. Акторы (роли)

| ID роли | Название | Тип | Кратко |
| --- | --- | --- | --- |
| R-01 | Игрок | Пользователь (человек) | Единственная пользовательская роль MVP. Ведёт партию через Фронтенд. |
| R-02 | Бэкенд | Системный участник / сервер | Создаёт сессии, хранит состояние, генерирует оба флота, исполняет ход Heatmap Bot, считает статистику, шлёт события. |
| R-03 | Фронтенд | Клиентское приложение | Десктопный клиент: UI, ввод игрока, REST/канал партии; сам правил боя не решает. |

> Администратор, зритель, второй человек-соперник (PvP) — **вне MVP**.

## 3. Права по объектам

### 3.1. Игровая сессия

| Действие | Кто | Условие |
| --- | --- | --- |
| Создать | Игрок → Фронтенд → Бэкенд | Успешная генерация и выдача расстановки; лимит менее 3 активных |
| Читать состояние | Игрок через Фронтенд; Бэкенд хранит | Пока состояние есть и TTL не истёк |
| Авто-reconnect | Фронтенд того же запуска | Нет другого активного соединения (A0093) |
| Удалить по TTL | Бэкенд | Idle 30 мин; клиенту оповещение FT-066 |
| Удалить при сбое heatmap | Бэкенд | После A0106 / FT-076 → FT-075 |
| Завершить GAME_OVER | Бэкенд | Уничтожение флота или явная сдача (A0092) |

### 3.2. Поля и выстрелы

| Действие | Кто | Условие |
| --- | --- | --- |
| Стрелять по полю ИИ | Игрок через Фронтенд | Свой ход, канал партии, валидные координаты |
| Стрелять по полю игрока | Бэкенд (Heatmap Bot) | Свой ход; не при пустой heatmap без ветки победы |
| Помечать MISS/HIT/SUNK / буфер | Бэкенд | FT-018…FT-021, FT-072 |

### 3.3. Статистика и локаль

| Действие | Кто | Условие |
| --- | --- | --- |
| Читать глобальную статистику | Игрок / Фронтенд | Запрос к Бэкенду |
| Писать записи по завершённым играм | Бэкенд | Только при GAME_OVER (A0088) |
| Считать среднее число выстрелов | Бэкенд | По всем записям завершённых игр (A0088) |
| Менять язык UI | Игрок / Фронтенд | Только локально (A0091) |
