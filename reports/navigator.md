# Навигатор MAS

С чего начать агенту. Детали ролей — `documentation/mas-description.md`. Стек — `reports/project-config.md`. Состояние этапа — `reports/pm-state.md`.

## Точка входа

Предпочтительный вход — агент `pm` / `/pm`. Пользователь общается с ПМ. Пустой `/pm` — статус и **один** следующий срез из `reports/checklist.md`, не все документы подряд.
После согласия ПМ **сам** гоняет конвейер среза. Прямые slash-команды допустимы (**сценарий S5**, не срез `S-05`), это не основной delivery.

## Сценарии

| ID | Когда | Первый шаг |
| --- | --- | --- |
| S1 | Новый репозиторий без требований | Не этот проект. MAS уже перенесена. |
| S2 | Код есть, требований нет | Не этот проект: пакет требований уже есть. |
| S3 | Описанный проект (этот репозиторий) | `/pm` (статус) → пользователь: «Запускай S-NN» → **новый чат с `pm`** с той же фразой. ПМ сам: бэк → тесты → прогон → фронт → тесты → прогон → гейт. Рапорт + сценарий проверки окна. «Утверждаю» / «срез согласован» → следующий срез. Прямые `/ft`…`/openai` — сценарий S5 (правка документов/кода в обход ПМ). |
| S4 | Отчёт заказчику | Команд `/report-weekly` нет. Факты только из существующих файлов `reports/`. |
| S5 | Обычный чат (не срез `S-05`) | Пользователь вызывает slash-команду напрямую. Оркестрация ПМ на паузе. |
