# Память агента аналитика
Этот файл хранит только устойчивые выводы, замечания и договоренности, которые пользователь явно попросил сохранить.

## Правила проекта
| Дата | Тема | Вывод / правило | Источник |
|------|------|------------------|----------|
| 2026-08-24 | Пути в промтах | Если в промте указана папка `docs`, это старые данные. Скорее всего имеется в виду `reports`. Перед записью туда уточнить у пользователя. | Явное указание пользователя в чате |
| 2026-08-25 | Вопросы к заказчику/команде | При задании вопросов по проекту агент всегда предлагает рекомендацию для ответа (чтобы можно было согласиться с ней или дать иной текст). | Явное указание пользователя в чате |
| 2026-08-25 | Нумерация файлов диаграмм | Новый процесс → новый файл с увеличенным номером (не перезаписывать чужие диаграммы). Пересоздание диаграммы по тому же процессу → тот же номер файла. | Явное указание пользователя в чате |
| 2026-08-25 | Имя файла диаграммы | Имя файла задаёт пользователь. Канон скилла (`diagram-mermaid-NNN` и т.п.) второстепенен: при явном имени в запросе сохранять/переименовывать именно так, без «предупреждений о каноне» как о блокере. | Явное указание пользователя в чате |
| 2026-08-25 | Запуск окна Фронтенда | Не запускать GUI PySide6 из терминала агента в чате: окно не видно на рабочем столе. Напоминать: проводник → `src/run-frontend.bat` или обычный PowerShell по `README.md` («Как открыть окно Фронтенда»). | Явное указание пользователя в чате |
| 2026-08-25 | Подпись стороны на экране | В окне Фронтенда игроку показывать «Компьютер» (EN: «Computer»), а не «Бэкенд» / «Backend». Замена только в UI. В глоссарии, ФТ, US, UC, модели и прочих документах канон — «Бэкенд». | Явное указание пользователя в чате |
| 2026-08-25 | Актуализация структуры | После создания новой папки или нового рабочего файла проекта обновить `.cursor/rules/rule-structure.mdc` (и синхронную копию `documentation/project-structure-v1-1.md`). Экземпляры уже описанного шаблона именования (`us-NNN`, `uc-NNN` и т.п.) в правило по одному не вносить. | Явное указание пользователя в чате |

## Термины и договоренности
| Термин | Значение | Где использовать |
|--------|----------|------------------|
| Бэкенд vs Компьютер | Канон документов — «Бэкенд». На экране Фронтенда для игрока — «Компьютер» (EN: «Computer»). | Требования, глоссарий, модель — Бэкенд; строки окна программы — Компьютер |
